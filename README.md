# Email2Post 📧➡️📝

**Простой и надежный способ превратить письма в статьи на вашем сайте.**

Email2Post — это PHP-скрипт, который подключается к вашему почтовому ящику через IMAP и автоматически публикует полученные письма как посты в блоге. Идеальное решение для контент-проектов, новостных рассылок и личных блогов.

## ✨ Ключевые возможности

*   **Автоматическая публикация:** Новые письма с указанного ящика автоматически становятся постами.
*   **Поддержка форматов:** Распознает и парсит **Markdown**, **BBCode**, а также обычный текст (Plain text) с автоопределением.
*   **Принудительный формат:** Можно указать формат прямо в письме с помощью шорткода `[format:markdown]`.
*   **Модерация:** Гибкие правила публикации через пароль в письме (`[p:пароль]`) или ручное подтверждение по email.
*   **Медиафайлы:** Автоматически сохраняет и отображает изображения из вложений письма (поддержка галерей).
*   **Шорткоды:** Управляйте публикацией прямо из текста письма: `[cut]`, `[end]`, `[status]`, `[tags]`.
*   **Чистые шаблоны:** Минималистичный, адаптивный HTML-шаблон (`minimal`) на нативном PHP. Легко кастомизируется.
*   **Безопасность:** Все данные хранятся в JSON, пароли не светятся в коде. Папка с данными защищена от прямого доступа.

## 🚀 Быстрый старт

### Требования
*   PHP 7.4 или выше
*   Расширение PHP `IMAP`
*   Доступ к почтовому ящику по IMAP (например, от Яндекс.Почты, Gmail, вашего хостинга)

### Установка

1.  Скачайте архив с проектом или склонируйте репозиторий.
2.  Загрузите содержимое в любую папку на вашем сервере (например, `/blog/` или `/email2post/`).
3.  Откройте в редакторе файл `data/config.php` и укажите свои настройки.
4.  Настройте cron для автоматической проверки почты.

### Настройка `config.php` (пример)

```php
<?php
return [
    // === Основное ===
    'base_url' => 'https://ваш-сайт.ru/папка-со-скриптом/',
    'debug' => false,

    // === Пути к данным (обычно не трогаем) ===
    'paths' => [
        'posts_email_file' => __DIR__ . '/posts_email.json',
        'pending_posts_file' => __DIR__ . '/pending_posts.json',
    ],

    // === Настройки почты (IMAP) ===
    'email' => [
        'enabled' => true,
        'imap' => [
            'host' => '{imap.ваш-провайдер.ru:993/imap/ssl}INBOX',
            'username' => 'ваш-логин@example.com',
            'password' => 'ВАШ_ПАРОЛЬ_ОТ_ПОЧТЫ',
        ],
        
        // === Правила публикации ===
        'publishing' => [
            'require_password' => true,       // Требовать пароль для публикации
            'default_status' => 'pending',    // Статус по умолчанию (published/pending)
        ],
        
        // Пароли для автоматической публикации
        'publish_passwords' => [
            'мойСекретныйПароль' => 'Имя Автора',
        ],
        
        // Настройки модерации (отправляются на email)
        'moderation' => [
            'admin_email' => 'admin@ваш-сайт.ru', // Куда отправлять ссылки для модерации
        ],
    ],

    // === Настройки сайта ===
    'site' => [
        'title' => 'Мой блог из Email',
        'description' => 'Публикации из email-писем',
    ],
    
    // === Настройки блога ===
    'blog' => [
        'posts_per_page' => 12,
    ],

    // === Настройки парсеров ===
    'parsers' => [
        'default' => 'auto', // auto, markdown, bbcode_dle, plain
        'common' => [
            'hashtags' => true,    // Превращать #теги в ссылки
            'autolinks' => true,   // Превращать ссылки в кликабельные
            'nl2br' => true,       // Конвертировать переносы строк в <br>
        ],
        'markdown' => ['enabled' => true],
        'bbcode_dle' => ['enabled' => true],
    ],
];
```

### Настройка Cron

Добавьте в планировщик задач (crontab) следующую команду для проверки новых писем, например, каждые 10 минут:

```bash
*/10 * * * * php /путь/до/вашей/папки/core/cron/email_parser.php
```

## 📝 Как писать письма для публикации

### Базовый пример (письмо для модерации)

```text
[p:мойСекретныйПароль]

# Заголовок моей статьи

Это **жирный** текст, а это *курсив*.

[cut]

А это продолжение статьи, которое будет видно только на странице самого поста.
```

### Пример с принудительным форматом

```text
[format:markdown]

## Это заголовок второго уровня

Текст с **разметкой** Markdown.

*   Пункт списка 1
*   Пункт списка 2
```

### Доступные шорткоды

| Шорткод | Действие |
|----------|----------|
| `[p:пароль]` | Автоматическая публикация, если пароль совпадает с `publish_passwords` в config.php. |
| `[status:published]` | Опубликовать пост сразу (даже если пароля нет, но он может уйти в `pending`). |
| `[cut]` | Всё, что **выше** этого маркера, становится кратким анонсом в ленте блога. Всё, что **ниже** — полным текстом. |
| `[end]` | Игнорировать весь текст после этого маркера. |
| `[tags "тег1, тег2"]` | Добавить теги к посту. |
| `[format:markdown]` | Принудительно указать формат. |

## 🗂️ Структура проекта

```
email2post/
├── core/           # Ядро системы
│   ├── cron/       # Скрипты для cron (email_parser.php)
│   ├── handlers/   # Обработчики (EmailHandler.php, BlogHandler.php)
│   ├── parsers/    # Парсеры контента (markdown, bbcode, plain)
│   └── init.php    # Точка входа для всего функционала
├── data/           # Данные (JSON-файлы с постами, вложения, конфиг)
├── templates/      # Шаблоны оформления
│   └── minimal/    # Базовый адаптивный шаблон
├── index.php       # Главный роутер сайта
└── .htaccess       # Правила для ЧПУ
```

## 🎨 Шаблон `minimal`

Шаблон использует нативный PHP и не требует сложных шаблонизаторов. Все переменные доступны через `$config`, `$post`, `$posts`. Вся логика парсинга контента уже встроена.

Вы можете легко изменить любой HTML-файл в папке `templates/minimal`.

## ⚠️ Важно

*   **Безопасность:** Убедитесь, что папка `data/` защищена от прямого доступа из браузера (проверьте `.htaccess`).
*   **IMAP:** Убедитесь, что на сервере установлено и активно расширение PHP `IMAP`.
*   **Cron:** Без настроенного cron скрипт не будет автоматически проверять новые письма. Вы также можете вызывать `core/cron/email_parser.php` вручную для отладки.
